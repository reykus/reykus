## About me

- Fullstack developer based in **Stockholm**. I speak Ukrainian and English, and I'm learning Swedish.
- **Backend in Python** (FastAPI, Flask, Django), **frontend in React and TypeScript**, and PHP when a project calls for it.
- I enjoy **Telegram bots**, **browser automation** and **local AI tooling**.
- I like working close to the hardware: ESP32-S3 and Arduino/C++.
- Learning and writing **Rust**: wgpu, ratatui, game engines and server plugins.
- I build products for **Swedish-speaking and Ukrainian-speaking** audiences.
- Currently working on a local AI agent that operates a PC (**NeedleOS**) and a 3D live map for a Rust-based Minecraft server (**Pumpkin**).
